- **Resumen**: Implementada la política de reintentos del crawler en
  `services/crawler/xtrace_crawler/jobs/backoff.py`: `next_attempt_delay(attempt, base=1 s, factor=2, cap=1 h)`

  `services/search-spike/**` y el resto del repo intactos.

- **Decisiones tomadas**:
  1. **Semántica de `attempt`**: número de intentos **ya fallidos** (1 = primer fallo); `attempt < 1`
     lanza `ValueError`. Retraso bruto = `min(base * factor ** (attempt - 1), cap)`; jitter completo
     sobre el bruto (contracts §3).
  2. **Validación estricta**: `base > 0`, `cap > 0`, `factor > 1` (el backoff debe crecer); mensajes
     claros. Detectada en test-first una violación del cap con `cap < base` en el primer intento
     (el retraso bruto debe aplicar el `min` desde el inicio) — corregida en la implementación, no
     debilitando el test.
  3. **Overflow-proof**: el crecimiento se calcula paso a paso con `min` por iteración (corta al
     alcanzar el cap); `next_attempt_delay(10_000)` devuelve exactamente el cap, sin `OverflowError`
     (probado).
  4. **Terminales (contracts §3)**: HTTP 404 y 410 (gone); mensajes con marcadores `removed`,
     `robots`, `terms of service`, `tos`, `404` (case-insensitive). **Transitorios**: 408/425/429,
     5xx y 403 (anti-bot legítimo → backoff, spec edge cases). Default **fail-safe**: excepciones y
     mensajes desconocidos → `TRANSIENT` (el reintento queda acotado por `max_attempts`, FR-008;
     nunca infinito).
  5. **API mínima y sin dependencias nuevas**: el módulo no importa `httpx` ni BD (los consumirá
     PR-024/PR-026/PR-027); recibe `int` (status), `str` (mensaje) o `BaseException`. `ErrorClass` es
     `StrEnum` (ruff UP042; Python 3.11) con valores estables `"transient"`/`"terminal"` para logs/BD.
  6. **Determinismo**: parámetro `rng: random.Random | None` (keyword-only); sin él se usa un
     `random.Random()` global del módulo. Tests con seed fijo y con doble `_FixedRng` que fija
     `uniform` en el extremo superior para asertar valores exactos del crecimiento.
- **Tests añadidos**: `tests/unit/test_backoff.py` — 17 tests: crecimiento exponencial exacto

  determinismo con seed (misma semilla → misma secuencia; semillas distintas → distintas),
