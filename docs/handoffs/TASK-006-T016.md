# Handoff TASK-006-T016

## Resumen

Se fijaron pruebas de seguridad para el gate de `sources.enabled` y el
manifest, rechazo de hosts fuera de allowlist antes de construir el cliente,
bloqueo de adapters crudos tanto en adquisición como en listado, y descarte de
`preview`, vídeo y tipos desconocidos sin invocar al fetcher. El contrato del
adapter XVIDEOS ejecuta la ruta real `get_visual_assets` con transporte fake y
comprueba además que no expone URL de vídeo completo, incluso con query strings.

## Tests y comandos

- `uv run --project services/api pytest services/api/tests/unit/test_refinement_security.py` — PASS (5 tests).
- `uv run --project services/crawler pytest services/crawler/tests/unit/test_refinement_asset_contract.py` — PASS (2 tests).
- Ruff y mypy de ambos tests — PASS.

## Cumplimiento

Todos los fixtures son sintéticos, no abren sockets y no requieren CAPTCHA,
autenticación, paywall, DRM, anti-bot ni bytes de vídeo completo.

## Revisión solicitada

Verificar que ninguna ruta puede saltarse el gate de compliance, derivar una
allowlist desde una URL no aprobada o materializar vídeo/preview.
