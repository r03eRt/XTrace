# Handoff PR-067 · Registro en el CLI (import dinámico) + seed `redgifs` (enabled=false) + gate

**Feature**: `specs/008-redgifs-adapter` · **Depende de**: PR-066 `DONE`.

## Resumen

`RedgifsAdapter` conectado al sistema exactamente como xvideos/erome (SC-006):
registro dinámico en `cli._default_registry()`, fila de seed con
`enabled=false` (manifest ya revisado en modo prueba, Decisión D4), y un test
de composición que ejercita el gate SEC-002 real de extremo a extremo.
Verificado además contra Supabase local real (no solo unit tests).

## Requisitos implementados

FR-007, SEC-002, DATA-001, SC-006, SC-007.

## Archivos modificados

- `services/crawler/xtrace_crawler/cli.py` — `_default_registry()`: import
  dinámico de `xtrace_crawler.adapters.redgifs.RedgifsAdapter()`, `real=True`
  (mismo patrón que xvideos/erome; sin wire de `storyboard_grid` — no aplica,
  redgifs no tiene sprite).
- `supabase/seed.sql` — fila `redgifs` (`adapter='redgifs'`, manifest D4:
  `access_method="api"`, `assets_accessed=["thumbnail"]`,
  `robots_reviewed=true`, `terms_reviewed=true`,
  `review_date="2026-08-19"`, `rate_limit` 2000ms/0.5rps, `enabled=false`).
  A diferencia de las filas `xvideos`/`erome` (deliberadamente
  `robots_reviewed=false`/`terms_reviewed=false` hasta revisión), la de
  `redgifs` refleja la revisión ya dada por el humano (D4) — paridad exacta
  con el manifest en código.
- `services/crawler/tests/unit/test_registry.py` —
  `test_default_registry_includes_redgifs_gated_by_enabled_in_db`: llama a la
  `_default_registry()` real del CLI y verifica que `redgifs` aparece
  registrado, que el gate deniega solo por `sources.enabled=false` (nunca por
  robots/terms, ya revisados) y que con `enabled_in_db=True` se resuelve el
  adapter real.

## Limitaciones

- El adapter sigue `enabled=false`: la validación real (backfill contra la API
  de redgifs) es PR-069, tras habilitación humana explícita en BD.
- No se añadió caso de `redgifs` en el patrón `_FakeAdapter` genérico de
  `test_registry.py` (ese patrón no distingue adapters reales por nombre en
  ningún caso existente de xvideos/erome/xhamster tampoco): en su lugar se
  probó `_default_registry()` real, que es la composición efectiva del CLI y
  cubre mejor SC-007/FR-007 para este PR.
