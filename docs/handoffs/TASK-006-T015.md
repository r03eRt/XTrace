# Handoff TASK-006-T015

## Resumen

Se fijaron regresiones de degradación para errores HTTP tipados 403/404,
timeout global y por candidato (incluida resolución y evaluación lenta),
materialización corrupta, límites de bytes/píxeles, duplicados/timestamps fuera
de rango y cancelación. Todas usan fakes in-memory y comprueban que el resultado
base no se reordena ni se interpola; la cancelación ejecuta el cleanup del
resolver.

## Tests y comandos

- `uv run --project services/api pytest services/api/tests/unit/test_refinement_fallback.py` — PASS (11 tests).
- Ruff y mypy del test — PASS.

## Limitaciones

El test no abre sockets ni escribe `frames`/VectorStore. Los errores HTTP son
excepciones controladas del resolver; la cobertura de allowlist y gate de
compliance queda en T016.

## Revisión solicitada

Comprobar que los fallbacks conservan timestamp/provenance base, que el timeout
marca `limited`, que los descartes no se interpolan y que la cancelación no se
traga.
