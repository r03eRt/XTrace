# Handoff — TASK-005-005

## Resumen

Se amplió exclusivamente la ruta adaptativa de `REINDEX` de XVIDEOS para solicitar
posiciones públicas `xv_N_t.jpg` del mismo path CDN observado en la página del vídeo.
El flujo legacy `INDEX_VIDEO` sigue usando únicamente las URLs declaradas en el HTML.
La expansión está acotada por la posición máxima observada y por la política aprobada
(`ceil(duración / 120 s)`, máximo 8); cada URL sigue pasando por la allowlist y por el
fetcher normal de assets. No se descarga ni almacena ningún vídeo completo.

## Requisitos implementados

- FR-001/FR-003/FR-005: selección adaptativa proporcional y centrada cuando la duración
  es fiable; degradación a los assets realmente descargables.
- FR-007/FR-015: timestamps derivados de la duración y posición de thumbnail; no se
  interpolan timestamps de assets que fallen.
- FR-008/FR-009: hook explícito de `REINDEX` para assets web permitidos, idempotente por
  vídeo; `INDEX_VIDEO` conserva el comportamiento histórico.
- SEC-001/SEC-002/SEC-004: solo URLs del mismo path/host observado y allowlisted, sin
  CAPTCHA, autenticación, endpoints ocultos ni vídeo completo.
- SC-001/SC-002: el lote real terminó con 104/104 vídeos y 1–8 frames por vídeo.
