- **Resumen**: Seed reproducible de fuentes de desarrollo en `supabase/seed.sql`
  (converge F4): el seed ahora registra de forma **idempotente**
  (`on conflict (name) do nothing`) las dos filas de desarrollo — `mock`

  **automáticamente** con `supabase db reset` (seed.sql); el SQL manual se
  conserva solo como referencia de los manifiestos y para la habilitación
  humana de xvideos (SEC-002). Validado end-to-end con el CLI real:
  `supabase db reset` → `xtrace-crawler sources --json` muestra ambas fuentes
  con sus manifiestos exactos; idempotencia comprobada re-ejecutando el seed
  (`INSERT 0 0`, 2 filas, valores intactos).
