# Handoff TASK-006-T031

## Resumen

El adapter XVIDEOS activa la validación anti-DNS-rebinding de
`SafeHTTPClient` para todas sus peticiones (`discover`, `get_video` y lectura
de assets), manteniendo la allowlist existente. Los tests usan
`MockTransport` y un resolver inyectable, sin realizar red real.

## Archivos modificados

- `services/crawler/xtrace_crawler/adapters/xvideos.py`
- `services/crawler/tests/unit/test_xvideos_adapter.py`

## Requisitos implementados

- SEC-001: allowlist y validación de IP resuelta antes de enviar la petición.
- SEC-002/003: no se añaden rutas de bypass ni acceso a vídeo completo.
- El resolver público determinista de `MockTransport` solo afecta a tests; la
  instancia operativa usa la resolución real de `SafeHTTPClient`.

## Riesgos y revisión

rechazar hosts no resolubles de forma fail-closed. Revisión independiente
pendiente antes de cerrar la tarea.
